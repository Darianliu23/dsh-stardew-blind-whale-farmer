# 沙漠节

## 几时去，怎么去

- 春季 **15–17 日**，巴士修好后才会举办。每天 **10:00** 开始，游戏时间照常走，**次日 2:00** 照常会晕倒。沙漠地图当天会换成 `DesertFestival`，用 `travel_to Desert` 坐巴士去，车票 **500g**。帕姆通常要在站台，游戏允许自驾时例外。回程用 `travel_to BusStop`。
- 本地依据：`Content/Data/PassiveFestivals.xnb` 的 `DesertFestival`，`BusStop.cs:47、133–152、303–306`，`Game1.cs:6452、9788–9798、12353–12362`，`Content/Maps/Desert-Festival.xnb` 的回程巴士动作 `DesertBus`。

## 卡利科三花蛋

- 三花蛋（`CalicoEgg`）是节日货币。来源包括沙漠挖蚯蚓点（**3–6 枚**）、骷髅洞穴砸石头和激活三花雕像、吉尔评级、威利钓鱼挑战、学者答题和猜赛跑赢家。赛跑可以找接待员猜赢家和领已赢的奖。
- 三花蛋能在三花蛋商店和当天的村民摊位换物品，也能花 **1 枚**请神秘人干预赛跑。**春 17 日结束的夜里会清掉三花蛋**，包括玩家持有和放在世界里的，想换的东西当天买完。
- 本地依据：`DesertFestival.cs:338–357、791–870、1050–1067、1099–1172、1178–1186、1290–1303、1682–1705、1755–1758`，`GameLocation.cs:14808–14825、15009–15014`，`Game1.cs:8514–8542`，`Content/Data/Objects.xnb`、`Content/Data/Shops.xnb`。

## 骷髅洞穴里的三花雕像

- 节日当天可以进**骷髅洞穴**，没有骷髅钥匙也能开洞里的门。三花雕像只在骷髅洞穴的部分楼层生成。走到未激活的雕像旁，用 `interact x=… y=…` 点雕像底座。每座激活时 **+1 评级**，往下到本轮新到达的每 **5 层**也会加分，跳洞按跨过的档位加。评级越高，洞里出蛋机会越大。
- 雕像有时给 **10 / 25 / 50 / 100 枚**三花蛋，也可能回满生命和体力、加速、降低怪物伤害，或没有额外效果。负面效果包括增加幽灵、飞蛇、骷髅、蝙蝠或怪物总量，臭虫变为刺客臭虫，木乃伊发怒，怪物伤害增加，食物效果减半，或晕倒时掉更多三花蛋。
- 想保住这一趟的收获就带上补给，留时间去找吉尔领奖。
- 本地依据：`MineShaft.cs:444–520、1389–1392、1779–1784、2692–2699、3031–3034、3053–3064、3751–3753`，`FarmerTeam.cs:398–435`，`GameLocation.cs:9365–9384`，`Content/Strings/1_6_Strings.zh-CN.xnb` 的 `DF_Mine_Explanation*` 和 `DF_Mine_CalicoStatue_Description_*`。

## 吉尔（Gil）和评级奖励

- 在沙漠节地图对 **(21,8)** 用 `interact`，有合格的当天最高评级时用 `dialogue` 确认提交。每人每天能领一次，游戏按显示的评级发奖。当天最高分由联机队伍共用。
- 本地依据：`Content/Maps/Desert-Festival.xnb` 的 `DesertGil`，`DesertFestival.cs:872–891、1099–1172、1920–1926`，`FarmerTeam.cs:474–487`，`Content/Data/Objects.xnb` 和 `Content/Strings/Objects.zh-CN.xnb`。

| 显示评级 | 三花蛋 | 额外奖励 |
| --- | ---: | --- |
| 1–4 | 1 | 矿工特供 ×1 |
| 5–9 | 10 | 咖啡 ×1 |
| 10–14 | 25 | 三倍浓缩咖啡 ×1 |
| 15–19 | 50 | 三倍浓缩咖啡 ×3 |
| 20–24 | 100 | 三倍浓缩咖啡 ×5 |
| 25–54 | 200 | 首次送吉尔的帽子，以后是三倍浓缩咖啡 ×5 |
| 55–999 | 500 | 魔法糖冰棍 ×1 |
| 1000 或以上 | 0 | 游戏提示异常分数 |

## 威利的钓鱼挑战

- 在沙漠节的钓鱼告示牌 **(14,14)** 或 **(15,14)** 用 `interact`，然后用 `dialogue choice=0` 接当天的任务。接完再钓，当天在节日地图找威利（`Willy`）交任务，三花蛋由该地图的任务完成逻辑发放。
- **第 1 天**钓 **3 条沙鱼**，完成后用 `interact npc=Willy` 交，奖励 **25 枚**。
- **第 2 天**钓 **1 条蝎鲤鱼**，完成后用 `interact npc=Willy` 交，奖励 **50 枚**。
- **第 3 天**从钓鱼小游戏的**宝箱**取出 **黄金浮漂**（`GoldenBobber`），用 `interact npc=Willy item=黄金浮漂` 交，奖励 **30 枚**。任务在身且背包里还没浮漂时，游戏会把打开的钓鱼宝箱的普通战利品换成它。
- 模组的 `FishTreasure` 开启后，自动钓鱼只在鱼较容易钓、还有足够进度时追宝箱。关闭时绿条跟鱼走，想拿浮漂可以由玩家手动追箱。
- 本地依据：`Content/Maps/Desert-Festival.xnb` 的 `DesertFishingBoard`，`DesertFestival.cs:730–739、1050–1067、1089–1097`，`FishingQuest.cs:214–224`，`ItemDeliveryQuest.cs:490–515`，`Quest.cs:610–611`，`FishingRod.cs:2844–2847`，模组 `GameActions.Fishing.cs:37–62`。

## 商店和摊位

先到 `DesertFestival`，用不带参数的 `open_shop` 看当前可用店铺和柜台位置。有多家时用 `open_shop shop_id=店ID` 选一家，它会走到柜台旁按动作键。开店后用 `buy` 按商店显示的价格或交换条件买。

| 店 | `shop_id` | 怎么开 |
| --- | --- | --- |
| 三花蛋商店 | `DesertFestival_EggShop` | **10:00** 后到柜台，用三花蛋换货，部分货品随日子变。 |
| 村民摊位 | `DesertFestival_` + 摊主英文内部名 | 每天安排 **2 个**摊位。只有实际摆摊的那天、摊主站在柜台后才开得了。比如今天阿比盖尔摆摊才用 `DesertFestival_Abigail`。`DesertFestival_Willy` 不存在，威利负责钓鱼挑战。 |
| 旅行货车 | `Traveler` | 沙漠节每天 **12:00** 开，货品按游戏商店数据。 |
| 沙漠商人 | `DesertTrade` | 到地图上的商人位置，用物品交换。 |
| 桑迪的绿洲商店 | `Sandy` | 先到 `SandyHouse` 再开，店主需要在场。 |

本地依据：`DesertFestival.cs:271–290、741–756、781–789、1804–1811、1968–1999`，`Desert.cs:50–71`，`Content/Maps/Desert-Festival.xnb`，`Content/Data/Shops.xnb` 的店铺条目和 `Traveler` 营业条件。
