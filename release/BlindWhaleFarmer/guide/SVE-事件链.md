# SVE 核心事件链、特别订单与新作物要点

> 本篇整理 SVE 1.15 中最容易卡住的四大主线解锁条件、特别订单材料与特色作物要点，均已核对 SVE 源码，无需死记事件编号。游戏里已接到的 SVE 剧情特别订单现在可以直接用 `special_orders` 查看实时进度。

## 一、爷爷的小屋（Grandpa's Shed）—— 第二个四季温室
- **作用**：修好后 1 楼（`Custom_GrandpasShed`）是超大室内空间，非常适合放小桶/罐头瓶/木桶；2 楼（`Custom_GrandpasShedGreenhouse`）是**全年四季可种的额外温室**。
- **推进步骤**：
  1. 进入爷爷小屋废墟（`Custom_GrandpasShedRuins`）触发初始发现剧情，之后等罗宾上门或来信触发修缮评估剧情。
  2. 剧情后任务日志会自动出现无期限特别订单 **《爷爷的小屋》**（`Robin3`，委托人 Robin）。
  3. 准备材料并放入小屋废墟里的投递箱（可用 `special_order_dropbox` 投递）：
     - **硬木 ×150**
     - **石头 ×600**
     - **铁锭 ×50**
     - **电池组 ×20**
  4. 交齐后数天罗宾完工，小屋自动替换为修缮版本与楼上温室。

## 二、极光葡萄园（Aurora Vineyard）—— 两条路线二选一
位于西煤矿森林（`Custom_ForestWest`）内，废弃状态为 `Custom_AuroraVineyard`。
- **前提**：完成社区中心（或走 Joja 路线完成社区发展），并进入西煤矿森林探索极光葡萄园触发前期剧情。
- **社区中心路线（祝尼魔 Apples 线）**：
  1. 在极光葡萄园内遇到祝尼魔 **Apples**，触发无期限特别订单（`Apples`）。
  2. 收集并交付 **杨桃 ×200**（提前在夏天/温室/姜岛大规模种杨桃）。
  3. 完成后 Apples 成为可社交村民（满好感可当室友），葡萄园翻新为 `Custom_AuroraVineyardRefurbished`。
- **Joja 路线（Morris 线）**：
  1. 完成 Joja 社区发展并推进 Morris 相关剧情后，触发无期限订单（`MorrisTod3`）。
  2. 购买并向 Morris 提交 **极光葡萄园地契**，可将葡萄园直接翻新为玩家资产（带独立酒窖与种植区）。

## 三、魔法森林传送枢纽（Enchanted Grove / Nexus）
- **作用**：`Custom_EnchantedGrove` 是 SVE 中后期快速传送中心，踩上各方向发光法阵（`MagicWarp`）即可直达多个远距离地点（`travel_to` 会自动利用已解锁的传送阵规划最短路线）。
- **核心开启条件**（全部满足后，在农场/法师塔附近触发法师引导剧情）：
  1. 拥有 **银河剑**。
  2. 已清理 **铁路巨石**（完成 Clint 的清理铁路巨石订单或对应剧情）。
  3. 已触发冒险家 **Alesia** 的剧情，并至少**通关一次姜岛火山地牢（到达第 10 层火山口）**。
- **解锁节奏**：
  - 初期自动连通**农场**与**法师塔地下室**（`Custom_WizardBasement`）。
  - 随好感与主线推进（精灵泉、冒险家公会、祝尼魔森林、极光葡萄园、城堡村哨站等），法阵逐个点亮，之后跨大半张地图去西森林/赤红荒原都能一步传送。

## 四、高地（Highlands）与赤红荒原（Crimson Badlands）
### 1. 马龙的小船 → 高地（`Custom_Highlands` / `Custom_HighlandsCavern`）
- **开启方式**：推进冒险家公会与姜岛/马龙好感后，触发马龙的无期限特别订单（`MarlonFay2`），将以下怪物战利品交给马龙（`MarlonFay`）：
  - **虚空精华 ×100**
  - **太阳精华 ×80**
  - **史莱姆泥 ×50**
  - **蝙蝠翅膀 ×40**
  - **虫肉 ×30**
- **解锁内容**：完成后马龙在公会后方开放小船前往高地；深入高地洞窟（`Custom_HighlandsCavern`）可解救高地矮人并解锁矮人商店，也能遇到新角色 **Lance（兰斯）**。

### 2. 赤红荒原（`Custom_CrimsonBadlands`）
- **定位**：SVE 最高难度刷宝战斗区（240×156 超大沙漠地图），盛产铱矿、五彩碎片、高价值怪物战利品与特色采集，但全图刷高攻高血怪物（含巨型怪物与远程攻击）。
- **备战底线**：至少银河/无限系武器 + 防御戒指 + 满组高回血食物（如奶酪/生命药水/SVE 战斗药剂）+ 大量炸弹 + **农场传送图腾/回城权杖**；血线低于一半立刻吃药，切勿贪怪到 24:00 以后。

## 六、SVE 新增作物速览（种子价格与实时库存用 `open_shop` 查）
- **常规季节高收益作物**（皮埃尔/特色商店出售）：
  - **黄瓜（Cucumber）**：夏季，可多次收获（每 2 天再生），适合稳健回本。
  - **奶油南瓜（Butternut Squash）**：秋季，单收高价值蔬菜。
  - **红薯（Sweet Potato）**：秋季，单收作物。
  - **金胡萝卜（Gold Carrot）**：春季（部分渠道解锁），高价作物，也是不少新村民的喜好礼物。
- **特殊/后期作物**（祝尼魔森林、西森林、高地或 Joja 百货获取）：
  - **萨拉尔浆果（Salal Berry）**、**史莱姆浆果（Slime Berry）**、**Joja 浆果（Joja Berry，Joja 线）**：均为每 4 天再生一次的多收作物，适合放温室或爷爷小屋温室长期产出。
  - **远古纤维（Ancient Fiber）**、**怪物菇（Monster Mushroom）**、**怪物果（Monster Fruit）**、**虚空根（Void Root）**、**Joja 蔬菜（Joja Veggie）**：多用于酿酒、高阶料理、药剂或高价值出货。
