# 农场类型专题

状态里“农场类型”一行会告诉你是哪种，开局对照下面调整前期路线：

- **标准农场**：可耕地最多、地形规整，适合大面积种地和规划洒水器田。
- **河边农场**：水多地少，农场里直接能钓镇上河和森林河的鱼，偶尔刷气泡；开局自带**熏鱼机**，走钓鱼加工路线非常赚。
- **森林农场**：西边空地每天刷新大树桩（硬木稳定来源）和季节采集品，特殊杂草必掉混合种子；农场池塘有机会钓到木跃鱼。
- **山顶农场**：西南小采石场每天刷石头、矿石和晶球，采矿等级越高矿越好（4 级出铁矿、7 级出金矿、10 级出铱矿）。入口可能被大树桩/大原木/大石头挡住，需要升级斧/镐。
- **荒野农场**：晚上农场会刷怪（随战斗等级变化），天黑后在农场干活记得带武器、留意血量。
- **四角农场**：分四块，分别类似森林（左上刷大树桩）、标准（右上大田）、池塘（左下）、山顶（右下小采石场），很适合联机分工或综合发展。
- **海滩农场**：**沙地上洒水器不起作用**（只有西南一块约 200 格的普通泥土能用洒水器），其余种地靠手动浇水；海边会冲上补给箱，农场里能直接钓海鱼。
- **草原农场**（1.6 新增）：开局自带鸡舍和 2 只鸡，且长有蓝色牧草（动物吃草好感翻倍）；第一天礼物箱给的是 15 个干草而不是防风草种子，适合早期养动物路线。
